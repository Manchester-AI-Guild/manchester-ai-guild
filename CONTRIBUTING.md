# Contributing to the Manchester AI Guild repositories

_Adopted 16 September 2026. Version 1._

## Before your first commit
1. **Link your commit email to your GitHub account** (Settings → Emails), or set `git config user.email` to your GitHub noreply address. Unlinked commits show as anonymous and cannot be credited or audited.
2. Use your real name in `git config user.name`.

## How changes land
- Work on a branch; open a pull request; one review before merge. This applies to everyone, including admins.
- Reference the issue in the PR title or body (`Closes #12`).
- Keep commit messages specific: what changed and why, one line, present tense.

## Issues
- Use the issue template. Every issue needs a label from the Guild set (governance, membership, events, comms, finance, tech, website, cookbook, launch, admin) and an assignee.
- `decision-needed` means the Council must decide before work continues; `blocked` means another issue must close first — say which.
- Close an issue only when the acceptance criteria in its body are met, with a closing comment saying what was done and where.

## Conduct
The Guild Code of Conduct applies to all repository activity.
