# Security Policy

## Supported scope
This repository is public and maintained by Manchester AI Guild maintainers.

## Reporting a vulnerability
Please do not disclose vulnerabilities publicly.

Report privately via GitHub Security Advisories if enabled, or open a private report to maintainers.

Include:
- affected path/component
- reproduction steps
- impact assessment
- suggested remediation

## Response targets
- Initial acknowledgement: within 3 business days
- Triage decision: within 7 business days
- Mitigation plan: as soon as validated
