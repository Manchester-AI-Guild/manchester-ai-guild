# Code of Conduct

**Date:** 2026-10-19
**Status:** DRAFT. Code of Conduct v2.8 (dated 12 October 2026) is awaiting Senior Leadership Team (SLT) sign-off. It is not yet adopted.

The Manchester AI Guild Code of Conduct sets the standard of behaviour we expect from Guild Members, SLT members, volunteers, speakers, contractors and anyone attending a Guild event. It also explains how to report a concern.

The authoritative text is kept in two places. Read either, and treat the operations repository as the source the other is generated from:

- [Code of Conduct on the Guild's `.github` repository](https://github.com/Manchester-AI-Guild/.github/blob/main/CODE_OF_CONDUCT.md)
- [Code of Conduct in the operations repository](https://github.com/Manchester-AI-Guild/manchester-ai-guild-operations/blob/main/policies/public/code-of-conduct.md)

**To report a concern:** email [report@manchesteraiguild.org](mailto:report@manchesteraiguild.org). It reaches the Risk & Governance Director. The Guild acknowledges reports within 5 working days.
