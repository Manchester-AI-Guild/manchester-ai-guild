# Operating model: index

**Date:** 2026-10-19
**Status:** DRAFT, awaiting Senior Leadership Team (SLT) approval. Nothing in this folder is adopted policy unless its own status line says FINAL.

This folder is the public home for the Manchester AI Guild's purpose, charter and operating model. It indexes the documents, with the status of each.

| Document | What it is | Status |
|---|---|---|
| [purpose-statement.md](./purpose-statement.md) | The Guild's purpose, as agreed by the SLT | FINAL (agreed 11 September 2026) |
| [charter-draft.md](./charter-draft.md) | Summary and pointers for the charter, draft v0.2 | DRAFT v0.2, awaiting SLT |
| [code-of-conduct.md](./code-of-conduct.md) | Pointer to the Code of Conduct and its reporting route | Code of Conduct v2.8 is a draft, awaiting SLT |
| [../operating-model.md](../operating-model.md) | The public summary of how the Guild runs: funding approach, member delivery, sustainability | Decided by default 16 September 2026; SLT ratification requested for 10 October 2026 |

## Reading order

1. Start with the [purpose statement](./purpose-statement.md).
2. Read the [charter draft](./charter-draft.md) for who the Guild serves, what it does and how it is governed.
3. Check the [operating model summary](../operating-model.md) for the funding and member delivery approach. The commercial and funding parts of that model are under review and are not yet live.
4. Read the [Code of Conduct](./code-of-conduct.md) for the standards of behaviour and how to report a concern.
